# Formica Wars

A browser strategy game about ant colonies at war in a huge backyard. Pick one of 24 real ant species, raise your colony, evolve your castes and take the yard from up to six rival colonies.

**Play:** open `index.html` in a browser, or play it online once GitHub Pages is turned on (see below).

## Features

- 24 real species, each with its own perk and look
- 12 castes, from workers and scouts to gatekeepers, stingers and raiders
- Up to seven colonies on one map
- Seasons, rain and snow, day and night
- Predators: beetles, spiders, antlions and a blue-tailed skink boss
- Aphid herds, territory, surface buildings and nest chambers
- Champion ants with war cries
- Argentine-only blood wasps you can unleash
- A 22-second first-person intro

## Controls

| Action | Input |
|---|---|
| Pan | Drag, or W A S D / arrow keys |
| Zoom | Scroll or pinch |
| Rally fighters | Tap the ground |
| Raid a rival | Tap a rival mound or outpost |
| Pause | Space |
| Follow an ant | F |
| Champion war cry | C |
| Jump to a battle | B |
| Unleash or recall blood wasps (Argentines) | V |
| Game speed | 1, 2, 4 |

## Play online with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose the **main** branch and the **/ (root)** folder, then **Save**.
4. After a minute the game is live at `https://<your-username>.github.io/formica-wars/`.

The whole game is a single self-contained `index.html` file. It only loads fonts from Google Fonts and needs no build step.
